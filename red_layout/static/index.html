Tipo do usuário

Escolha o tipo. A Plataforma Central cria o login NomeSobrenome com senha Nome@ano. A Monday recebe convite de membro. Comprador não entra sozinho no SysCall: ao criar, o painel pede para cadastrar manualmente (Operador / RedPre), com user e senha iguais à parte antes do @.

Ative somente para compradores. Desligado, nada é criado na GoTo.

Informe o e-mail para verificar se o usuário já existe.

Ao escolher um número, a GoTo recebe o nome, o identificador de chamada e encaminha as chamadas para o ramal da pessoa.

A criação atribui GoTo Connect Standard, grupo Compradores, idioma Português (Brasil) e fuso de Brasília.

A baia segue a máquina escolhida.
